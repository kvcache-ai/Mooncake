:::{dropdown} Data notes

- The snapshot is refreshed during documentation deployment, at most once per day
  for each endpoint. Collection times and missing data are shown above.
- **Day / week / month** preserve the `recent` API values and exclude mirrors.
  They do not follow the date filter and can differ from sums of daily records.
  **Selected range** is calculated from the daily `overall` series.
- **All dates** means available history, not lifetime downloads. PyPIStats
  documents roughly 180 days of retention; all dates actually returned are kept.
  Dates and timestamps use UTC.
- Missing values are shown as **—**, not zero. Totals include returned records
  only. Downloads include repeated installations and CI activity, not unique users.
- Python and operating system statistics always exclude mirrors. They are
  separate breakdowns of the same downloads and must not be added together.
- The package list is discovered from the [PyPI index](https://pypi.org/simple/).
  TestPyPI is excluded. Source: [PyPIStats API](https://pypistats.org/api/).
:::
